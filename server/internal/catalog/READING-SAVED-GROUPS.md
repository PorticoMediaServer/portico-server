# Dynamic Reading group references — Root30

A group save persists one current-profile/server/library/typed-kind/accepted-private-series-key reference. It never snapshots members or changes leaf flags. Private storage contains no label, artwork, count, cursor, catalogue entity or audio identity. The opaque reference identity is immutable. A tombstone and revision survive normal removal/re-add; original operation receipts remain immutable and retired-operation fences prevent replay after receipt pruning. An unsaved status read mints no reference.

Target add/status/remove use the canonical library/groupKind/43-character ReadingSeriesID target. A same-transaction resolver independently re-admits the original normal selected profile with no grant, resolves its current library/restriction scope and ready attribution generation, then finds the exact accepted private key under the complete typed/current-publication/visible group predicate. Labels use owner spelling/frequency/binary ties; counts cover that full predicate; selected cover metadata is IDs-bounded and local. No source acquisition or playback/download authority is added. The public target response contains membership/revision/reference/operation data, not cached group metadata.

Root30's reference-only removal is distinct. Its command receives an opaque reference ID, operation ID and captured reference revision. It checks only the current original normal profile/server and exact own reference in one transaction, then changes that reference/tombstone and minimal owner revision. It never selects a target key, resolves a group/library, expands members or returns target metadata. Foreign and absent references both miss. A later target re-add is preserved when an old removal operation replays. The HTTP postproof is also reference-only, and returns the stored original result.

Profile erasure deletes references, receipts and the owner reference revision. Existing bounded receipt maintenance includes the new receipt table. The directly edited pre-release baseline gains normalized private tables, leading owner/server indexes, receipt expiry index and an immutable-reference-identity trigger. No schema execution, generated schema metadata, migration, test or build accompanies this source. Release16 owns official metadata/artifacts and checkpoint adoption.

The Saved-specific wire alternative is `SavedReadingGroupCard`, discriminator `reading_group`, with an opaque reference ID rather than an entity ID. Visible cards carry only fresh accepted title/count/cover and exact library/group navigation. Hidden cards' encoder strips all target/metadata/navigation fields and permits only private reference/removal bookkeeping. `SavedCard` is a Saved-only union; global catalogue kinds, item effects, header entities and selection grants are unchanged.

Current source slice includes private storage, current resolver, target/reference API declarations, card/union models and real classification/negative source cases. The full mixed Saved query/cursor composition, Saved-specific client/rendering and group-page caller are still being authored; this prerequisite is not screen completion and does not yet put group cards into Saved. No fake effect or runtime claim is made.
