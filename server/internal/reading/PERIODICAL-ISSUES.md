# Typed periodical issue membership

This endpoint reads one existing accepted series in one book library. It does not infer a publication type, series, issue date or cadence. Every member must be in the same immutable ready attribution generation with the requested accepted `magazine` or `newspaper` type, actual series ID and accepted issue date. Newspaper membership requires day precision; a month never supplies an invented newspaper day. The ordinary current canonical-primary publication and viewer/library/profile restriction predicate run before pagination in the same snapshot.

The fixed canonical order is issue-date string descending, then actual item ID descending. ISO month precision is retained as a month value; mixed precision has deterministic lexical placement and does not imply a calendar day. No client sample sort or view direction affects membership. The type/date/series ready index supports the seek.

The existing signed Reading cursor framing is reused with a distinct periodical-issues-v1 plus requested-type scope. It binds the current ready namespace/input/generation, catalogue and viewer revisions, profile/authority/restriction fence, library, exact series, type, page limit, complete date/item tuple digest and original expiry. Cross-series, cross-type, generic-series and stale-generation reuse refuse. An anchor is resolved again under that exact current eligibility predicate before its full tuple is compared. Subsequent pages retain original expiry.

The response publishes actual library, series and type, dated Reading items and the optional continuation. Items use existing title/cover/author provenance. It does not start playback, write reading progress, create a saved publication identity, or grant source bytes. No group grid, pivot availability, calendar or whole-library periodical completion is claimed by this endpoint alone.

Official API generation belongs to the Release16 checkpoint batch.

The companion group endpoint groups only that same real eligible membership. It counts all eligible visible issues before selecting a group page or latest issue. Labels use the accepted owner spelling first, then frequency and binary ties, matching existing series composition. Latest means date string descending and item ID descending. Groups sort by canonical series key and series ID; their signed continuation uses the actual latest member as the indexed anchor and verifies the full group-key/ID digest. Its distinct periodical-groups-v1 scope refuses issue-page and generic-series cursors. No capped preview determines counts, and no other series member or publication type leaks into a group. An empty eligible scope returns an empty page.

The optional `issueDate` query is an exact accepted calendar date (YYYY-MM for a magazine month or YYYY-MM-DD; newspapers require day precision). It filters the complete eligible snapshot before LIMIT and anchor lookup. It does not select all days in a month or manufacture day precision. A valid date with no visible eligible issue returns an empty page. Nonempty date is echoed in the optional response issueDate and bound into the signed cursor domain, so date/unfiltered and cross-date continuation reuse refuse. Omitted date retains the existing cursor domain and behavior. The original principal, visibility predicate, ready generation and original cursor expiry remain unchanged.

Year selection: the response years array contains actual four-digit calendar years and whole-visible-series issueCount, descending, at most9999 years and safe-integer counts. It is composed under the same original-principal SeriesScope/Visible/current-primary ready snapshot before either exact-date or year filtering and before pagination. Optional year selects only actual accepted dates in that year using a bounded lexical range, with no missing editions generated. Date and year must agree when both supplied. The optional year echo and nonempty year signed domain refuse cross-year/unfiltered continuation reuse; omitted year preserves the existing domain. A valid year with no eligible issues returns an empty page. No cadence, type, count from a loaded page, or progress is inferred.

Newspaper month selection uses an optional actual YYYY-MM calendar month, with exact month echo and a bounded days array of actual accepted day dates plus whole-visible-date issueCount. Day membership is counted under the same ready principal/visibility/current-primary snapshot after month restriction but before exact date, year or page filters; there are at most31 actual dates, in ascending order. A date may have multiple admitted editions, all retained in its count and issue pages. Month/year/date must agree; month is refused for magazines. The month range precedes LIMIT and anchor resolution and binds a distinct nonempty signed month domain without resetting expiry. No-month remains compatible; no-match validmonth returns an empty issue page and empty days. Missing dates remain absent, with no read/progress/cadence claim.
Discover New issues is explicitly opted into with newIssuesLimit1..20 and one library. It is magazine-only, book-library/current ebook EPUB/PDF, actual accepted type+series+issueDate from the current ready generation. The exact live SeriesScope and existing visibility predicate apply before LIMIT. Order is actual catalogue added_ms descending plus actual item ID descending, not issueDate or a client sample. The row reuses dated item projection, has no guessed age threshold, unread claim, New badge or See all. Absent unsupported facts mean absent membership, and old requests do not opt in. Newspaper composition remains separate.
