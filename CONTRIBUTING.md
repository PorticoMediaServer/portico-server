# Contributing to Portico

Portico is developed in the open, and user feedback is an important part of that process.

## What we welcome

- Clear bug reports with steps to reproduce the problem.
- Feature requests that explain the user need.
- Compatibility reports for media formats, devices, operating systems, and hardware acceleration.
- Documentation corrections submitted as issues.
- Constructive discussion in existing issues.

Please search existing issues first. Include the Portico version, operating system, installation method, relevant logs with private information removed, and the smallest reproducible example you can provide. Screenshots are helpful when the problem is visual.

## External code contributions

Portico does not accept external code contributions. External pull requests will be closed without review.

## Security issues

Do not report suspected vulnerabilities in a public issue. Follow [SECURITY.md](SECURITY.md) instead.
