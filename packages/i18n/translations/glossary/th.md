# Thai (th) glossary — machine translation, needs native-speaker review

Address form: polite neutral, as Thai streaming apps use (Netflix/Disney+ Hotstar/TrueID
register). No gendered particles (ครับ/ค่ะ) in UI labels or sentences; impersonal,
instruction-style phrasing. No spaces between Thai words; spaces only around Latin
script/numbers where Thai punctuation requires (e.g. `1080p`, `Portico Account`,
`192.168.1.20:32500`).

## Typography / punctuation

- Ellipsis … (U+2026) kept as in source for progress states (กำลังโหลด…).
- Quotation: Thai text uses “…” (curly) as in source; no ASCII quotes, no ASCII
  apostrophe anywhere (ICU quoting). English possessives restructured, e.g.
  “Confirm the metadata source” → ยืนยันแหล่งข้อมูลเมตาต้า.
- Percent/unit spacing: `{percent}%`, `{value} Mbps`, `192.168.1.20:32500` kept tight.
- Arrows `→` and middots `·` kept (e.g. `{used} · {free}`, S{season} · E{episode}).
- Thai duration shorthand: ชม. / น. / วิ in compact labels; full ชั่วโมง/นาที/วินาที
  in sentences and plurals. Counters use Thai classifiers where natural
  (เรื่อง for titles, ตอน for episodes, คน for people, ครั้ง for plays, ไฟล์ for files).
- Plurals: Thai has only `other`; every plural uses `{x, plural, other {...}}`
  (plus kept `=0` branches where the English had them). Select keys kept exactly.

## Judgement calls a reviewer should check

- รายการ for "show/series/title" is deliberately generic; รายการทีวี used where the
  English clearly means a TV show (search chips, library kinds).
- "Channel" (Library Channels feature) → ช่อง (same as live-TV channels).
- Relative times use postposed ที่แล้ว (e.g. 5 นาทีที่แล้ว).
- Sort option “Own order” → ลำดับของตัวเอง (per-group custom order).
- “Local metadata only” → เฉพาะข้อมูลในเครื่อง / ข้อมูลเมตาต้าในเครื่อง.
- DVR/“capture” vocabulary → บันทึก/จับ (recording capture unavailable → จับไม่ได้).
- Long server-console sentences were compressed to stay scannable; verify technical
  accuracy (ffmpeg, storage, secure-connection, live-source sections).
- Duration sentence “Up for {duration}” → เปิด{duration} (server uptime).
- `player.playAnyway` / `web.together.playAnyway` → ยังเล่น (not ยังเล่นต่อ) to keep
  it short; confirm tone.
- Language names under `language.*` translated into Thai (อังกฤษ, ญี่ปุ่น, …);
  `locale.*` keys untouched per the rules.
