# Finnish (fi) glossary

Address: informal **sinä**-style, consistent with Finnish streaming apps
(Netflix FI uses sinuttelu). Imperatives are 2nd-person singular
(“Valitse”, “Yritä uudelleen”); system processes use the passive
(“Ladataan”, “Tarkistetaan”, “Valmistellaan”).

## Typography and punctuation

- Quotes: Finnish high–low **”...”** (U+201D/U+201E). Never ASCII `"`.
- Apostrophe: always **’** (U+2019); Finnish text rarely needs one.
- Ellipsis: **…** (U+2026) on trailing menu items, matching the English.
- Percent: space before **%** (“{n} %”), per Finnish convention.
- Ranges use en dash (“1–100”, “{min}–{max}”); arrows “→” kept.
- Units abbreviated as in Finnish tech UIs: t (tunti), min, s,
  Mt (megatavua), Gt (gigatavua), Mb/s.

## Grammar: placeholders and case endings

Finnish is agglutinative, so a placeholder can never take a case ending.
Rephrase so every argument stays nominative:

- Colon pattern: “Koska katsoit: {title}”, “Lisätty: {name}”,
  “Toista: {title}”, “Näytä etusivulla: {title}”.
- Nominative-subject pattern where possible: “{title} ei ole enää
  tällä palvelimella.”, “{device} ei vastannut.”
- Passive constructions avoid address entirely: “Ladataan”, “Yritetään
  uudelleen {n} sekunnin kuluttua”.
- Numeral agreement inside plurals: 1 → nominative singular
  (“# jakso”, “# tallenne”), 2+ → partitive (“# jaksoa”, “# tallennetta”);
  time-until uses the genitive in both branches (“# sekunnin kuluttua”).

Finnish `Intl.PluralRules` needs **one/other**; every target plural has
both, including =0 branches and the added `one` in `lib.countAtLeast`.

## Judgement calls a reviewer should know

- **Portico Account** (and Services) is kept literally everywhere,
  compounded as “Portico Account -tilisi” so the validator sees it.
- **Watch Together**, **AirPlay**, **Google Cast**, **Quick Connect**,
  **Dolby Vision**, **mpv**, **HDHomeRun**, **TMDB/TheTVDB/MusicBrainz**,
  **rclone**, **MCP**, **API** kept as names.
- Language names are Finnish exonyms (Englanti, Ranska, Saksa, …),
  matching the fr/de precedent (they translate rather than endonymise).
- “LIVE” badge → **SUORA** (Finnish broadcast convention).
- “Label” (parental/content label) → **Merkintä**; “Tag” → **Tunniste**.
- “Collection” → **Kokoelma**; “Playlist” → **Soittolista**;
  “Row” (home) → **Rivi**; “Grid/List” views → **Ruudukko/Lista**.
- Error-title selects keep the impersonal passive (“Ei latautunut”,
  “Ei voitu tallentaa”) rather than assigning blame.
- Sign-in error strings kept to one sentence each where the English is
  one sentence; multi-sentence English stays multi-sentence.
- **confirm.word.delete** (“delete”) → “poista”: typed to confirm, so
  the Finnish word is what the UI must ask for — flag if the confirm
  prompt shows the English word instead.
- Long server-console nouns kept short where possible, but Finnish runs
  long: e.g. “Tallennussäännöt”, “Etäkäyttö”, “Käyttöoikeustunnukset”.
