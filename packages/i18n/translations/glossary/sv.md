# Swedish (sv) glossary — Portico UI

Address form: **informal "du"** throughout (din/ditt/du), following Netflix/SVT Play/Apple TV
conventions in Sweden. No formal "ni" anywhere. Impersonal passives ("Det gick inte att…",
"Spelas upp…") used for system messages where Swedish avoids a subject.

## Punctuation & typography

- Quotes: Swedish ”…” (U+201D/U+201C), never English "…". Nested in ICU/select text kept
  balanced. Example: Tog bort ”{title}” från spellistan.
- Apostrophe: NEVER ASCII `'`. Swedish genitive needs none ({name}s grupp,
  Porticos). U+2019 only appears inside quoted English-style text if at all — currently unused.
- Ellipsis: … (U+2026) kept exactly where English has it (menu items opening a further
  step: Lägg till i spellista …; "Saving…" → Sparar …). Three dots "..." never used.
- Middle dot: · (U+00B7) kept in compound labels (Automatiskt · {quality}, {used} · {free}).
- En dash ranges: 1–100, {min}–{max}, A–Z kept literally (matching de/fr which keep A–Z
  even though Swedish collation is A–Ö — reviewer may want A–Ö/Ö–A).
- Space before % ("50 %", "{count} %") per Språkrådet; Mbps always Mbit/s.
- Sentence case for buttons/tabs/menus (only first word capitalised: "Lägg till spellista"),
  EXCEPT named features (Fortsätt titta, Kommande, Min lista, Favoriter, Titta tillsammans,
  Live-TV, Bibliotekskanaler, Anpassa Hem, Portico Account).
- No full stop on buttons, menu items, titles; full sentences (errors, ledes, bodies) end
  with a period. Exclamation marks only where English has them.
- Leading/trailing spaces preserved exactly (validated on import).
- Time formats: "2 minutes" → 2 minuter; countdown "{seconds}s" → {seconds} s;
  clock times pass through ({time}, 8:30/20:15 examples kept).
- “TV:n” definite forms used for "the TV" (cast.takeover etc.).

## Judgement calls / known weak spots for the reviewer

1. **Forced subtitles** → "forcerade undertexter" ("Endast forcerade"). Swedish DVD/BD
   convention varies (tvingade/forcerade); worth a native check.
2. **A–Z sort labels** kept as A–Z/Z–A like de/fr; Swedish alphabet ends in Ö — consider
   A–Ö/Ö–A.
3. **"hen"** used once (web.access.roleConfirmMember: "delats med hen") for gender-neutral
   "them". Correct modern Swedish, but flag if tone should be more conservative.
4. **Captions vs subtitles**: player captions on/off → "Slå på/stäng av textning"
   (textning = CC-style), everything else "undertexter". Consistent but reviewer should confirm.
5. **"Tuner"/"tuners"** kept as loanwords (standard in Swedish TV tech); plural "tuners".
6. **Keep {name} for …** (maintenance.keepCategory) → "Behåll {name} i" — terse; source is
   "Keep {name} for" with a duration following. Fine in context.
7. **web.filters.direction count/size/order branches** translated (Färst/Flest/Minst/Störst/
   Först till sist…) — check against final UI.
8. **server.routes engine names** ("enhetens egen spelare", "mpv-spelaren") are lowercase
   mid-sentence fragments by design (they fill "…failed on {engine}").
9. **Setup copy** ("Vi installerar servern…") uses "vi" (Portico speaking) — matches source
   "Let's set up your server". Elsewhere the app never says "vi/jag".
10. **Long server-console strings** (storage, backup, live-TV, secure-connection ledes) are
    faithful but long; Swedish compounds (säkerhetskopieringsmapp, återställningsägare)
    are correct though dense.
11. **"Title"** → Titel everywhere, including "Title to search for" → "Titel att söka efter".
12. **title.starring/medverkande**: "Starring {name}" (home row) → "Med {name}"; person page
    "Starring {names}" → "Med {names}" — terse but standard (Netflix SE uses "Med").
13. **guide.next** "Nästa: {title} {time}" — preposition dropped like the English ("Next: X at Y"
    → "Nästa: X Y"); reads fine with time formatting.
14. **"Up to {rating}"** (server.people.upTo) → "upp till {rating}" — rating value inserted.
15. **web.metadata.numberOffsetHelp** example "(1, 2, 3 …)" kept with English-style ellipsis
    inside parens — fine.
16. **builder.empty.body** quotes English examples translated: ”bara filmer från 1985”,
    ”inget annat än en serie”.
