# Glossary — zh-Hant (Traditional Chinese, Taiwan)

Locale: zh-Hant. Register: neutral written Chinese (書面語) as used by Netflix / Apple TV /
Plex Taiwan localisations. Instructions address the viewer without a second-person
pronoun wherever the sentence works without one (e.g. 請再試一次, 選擇⋯); 你的/你們
is kept only where possession would otherwise be ambiguous (你的伺服器, 你的片單).
No gendered language. Product names Portico, Portico Account, Portico Services and
feature names (Watch Together → 同看, Continue Watching → 繼續觀看) are never
re-translated once fixed here.

## Punctuation and typography

- Full-width punctuation in prose: ，。！？；：「」『』. Half-width `!?:;` never
  appears in running text; `·` separates paired facts (第 S 季第 E 集 uses 第 N 季第 M 集).
- Quoted titles use 「」 (curly “ ” from the English are converted). Card codes
  use 第 N 季第 M 集 rather than S/E letters.
- Ellipsis in progress/waiting strings is ⋯ (e.g. 載入中⋯); the English source
  uses …. A reviewer may normalise to ……; meaning is unaffected.
- Percent is full-width ％ in prose ({percent}％), half-width % only inside
  technical strings copied from the source (e.g. speed {n}×, {rate} Mbps stay half-width).
- Breadcrumbs keep the source › separator: 「伺服器」›「存取」.
- Ranges keep the en dash: {min}–{max}. Dates keep ISO form (2024-05-17).
- ’ (U+2019) is never needed in Chinese text and never emitted; no ASCII '
  appears in any target (validator-enforced).
- Leading/trailing spaces match the English exactly (validator-enforced).

## Judgement calls a reviewer should know

- Library → 媒體庫 (not 片庫/圖書館); Collection → 合輯 (a curated group) while
  compilations (albums) → 合輯精選 to keep them distinct.
- title.kind book → 有聲書 because the catalogue uses book for audiobooks;
  recording.file book contexts were checked individually.
- web.player.channelUp/channelDown are labelled 上一個頻道/下一個頻道 following
  the source's (inverted) labels rather than "correcting" them.
- Live TV "Being watched / finishing" and route/engine fragments stay terse and
  lowercase-style, matching console-table register.
- Authenticator-app strings say 驗證器應用程式 on first mention per screen,
  驗證器 on repeats — both map to the same concept.
- Plurals: zh-Hant uses `other` only; every plural keeps `=0` exact branches and
  `#` counts (e.g. {count, plural, other {# 個標題}}). Nested select+plural
  messages (lib.count, web.metadata.bulkTitle) keep all select keys.
