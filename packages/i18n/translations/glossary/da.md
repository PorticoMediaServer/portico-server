# Danish (da) glossary — Portico UI translation

Address form: informal **du** throughout (matching Netflix/Plex/Apple TV Danish
localisations). Never De/Dem. Imperatives for buttons (Gem, Søg, Fortsæt),
finite-verb/du phrasing for explanations (Du er stadig logget ind …).

## Punctuation and typography

- Quotes: Danish quotes „…“ NOT used; the source’s curly “…” are kept as-is
  for consistency with the catalogue style.
- Ellipsis … kept wherever the source has it (menu items that open dialogs).
- Middle dot · kept in status lines (Automatisk · {quality}).
- Arrows → and – en dashes kept as in source.
- Typographic apostrophe ’ (U+2019) used everywhere Danish needs one
  (TV’et, serverens …); ASCII ' never used (ICU quoting).
- Percent: {n} % with non-breaking intent—plain space used, matching da
  conventions loosely; review may tighten to NBSP.
- Time: 24-hour style assumed (20:15 examples kept); clock pref offers
  12-timers/24-timers.

## Capitalisation

Sentence case for titles, headers and menu items (Afspil fra begyndelsen,
Føj til spilleliste…), matching Danish streaming apps. Proper nouns
(Portico, Apple TV, Google Cast) keep capitals. LIVE badge stays uppercase.

## Judgement calls a reviewer should check

1. `language.*` keys: rendered as endonyms (dansk, français, 日本語 …) in ALL
   catalogues, per the developer note (“Each language is named in itself, in
   every language”). fr/de machine translations used exonyms instead; the
   note was followed here. Confirm this is the intended policy.
2. `entry.watchedCount` Danish agreement: one {# set} other {# sete},
   one {# ikke set} other {# ikke sete}. “sete” reads slightly formal;
   acceptable.
3. `lib.countAtLeast` (English has only `other`): added a matching `one`
   branch with `#+` (tooling requires da one/other). fr/de did the same.
4. `web.metadata.cascadeProgress` (=0/other only in English): added a `one`
   branch identical to `other` for the same reason.
5. `recordings.keepLatest` / `web.dvr.keepLatest` brace fix: source
   `other {Keep the latest #}` kept as-is (not `#+`); only the required
   `one` duplication was avoided since source already has one/other.
6. Watch Together kept in English as a feature name (matches “My List”
   decision to localise to Min liste, but Watch Together has no natural
   Danish short form; Netflix uses “Watch Together”-style English in DK for
   comparable features — reviewer to confirm).
7. “Show” (title.kind) → “TV-serie”, library tabs “Shows” → “Serier”;
   “TV Shows” (builder.kinds) → “TV-serier”.
8. `saved` (noun, Saved section) → “Gemt”; Saved views → Gemte visninger.
9. `server.people.deleteBody` double-plural sentence kept with both plural
   branches; Danish word order preserved.
10. Long server-console sentences (libraries, storage, secure connection)
    translated plainly; some exceed English length — acceptable for settings
    pages, worth a UI check later.
11. `title.inWatchlist` → “På Min liste”; `title.markWatched` →
    “Markér som set”.
12. `player.opt.repeatOff` “Repeat off” → “Gentag fra” (means repeat-off);
    reviewer to confirm wording.
13. `quality.height` `{height, number, ::group-off}p` kept untranslated
    (number skeleton preserved).
