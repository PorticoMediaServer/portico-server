# Glossary — Ukrainian (uk)

Machine translation, marked for native-speaker review. Genuine Ukrainian
vocabulary and orthography throughout; Russian calques deliberately avoided
(налаштування not *настройки, пристрій not *устройство, відтворити not
*воспроизвести, назва not *название, зіставлення not *совпадение,
обліковий запис not *аккаунт, завантажити not *скачать).

## Address form

Polite plural **ви** everywhere (imperatives: Спробуйте, Перевірте,
Виберіть, Увійдіть). Matches Netflix/Apple/Google Ukrainian conventions.
No ти-forms. Impersonal -но/-то passives (Збережено, Видалено) where the
English is agentless.

## Plurals

one/few/many/other everywhere (Intl.PluralRules uk). Noun forms used:

- секунда: секунду/секунди/секунд/секунди; хвилина, година likewise
- назва: назва/назви/назв/назви; елемент, файл, запис, тюнер, канал,
  серія, сезон, альбом, пісня, плейлист, компонент, подія, спроба,
  голос, зірка, глава, сеанс, потік, код — same pattern
- день: день/дні/днів/дня; рік implicit; раз: раз/рази/разів/рази
- Impersonal -но/-то forms (Збережено, Видалено, Оновлено) used where the
  branch subject varies, avoiding agreement traps.

## Punctuation / typography

- Quotes: «…» (Ukrainian/French style guillemets), incl. nested UI labels.
- Apostrophe: ’ (U+2019) everywhere, incl. Ukrainian ’ in ім’я,
  пам’ять, зв’язок, сім’я-type words.
- Ellipsis … (U+2026) kept as in source; terminal … in actions
  (Завантажити…) kept.
- Arrows › in Settings paths kept; → in ranges kept.
- Capitalisation: sentence case for buttons/labels as in source; feature
  names (Спільний перегляд, Прямий ефір, Мій список) quoted with «…»
  when referenced inside sentences.
- No non-breaking spaces added; English % / p / × units kept adjacent
  ({value}%, {height}p, {speed}×); time abbreviations spaced (10 хв).

## Judgement calls for the reviewer

- Quoted button labels inside sentences use the translated label
  (fr/de/ru convention), e.g. replacedBody quotes «Використати інший
  сервер або обліковий запис».
- Server-console paths guessed in Ukrainian (Сервер › Доступ, Сервер ›
  Бібліотеки › Налаштування, Сервер › Віддалений доступ › Захищене
  з’єднання, Сервер › Прямий ефір і запис ТБ, Налаштування › Обліковий
  запис сервера): verify against the actual console section names when
  those are translated.
- title.missing / deleteVersion.body use feminine «Відсутня» (назва).
- title.born avoids gender with «Дата народження: {date}».
- S/E codes: card.episodeCode expanded to words (Сезон N · серія M);
  downloads.title.episode and title.episodeCode keep S/E codes.
- duration.hoursMinutes uses год/хв (Ukrainian standard, not ч/мин).
- web.setup.welcomeLede renders "Let's" as «Давайте».
- A few early units say Тека where later ones say Папка; prefer Папка.
- Recovery codes vary (Резервні коди vs Коди відновлення); prefer
  Резервні коди.
- «Перегляд» doubles as viewing and the Saved-tab noun; fine in context.
