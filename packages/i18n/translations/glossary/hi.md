# Hindi (hi) glossary — Portico UI translation

Machine-translated; needs native review. Register: the आप form everywhere
(polite plural imperatives — चुनें, करें, जाएँ — and सकेंगे/जाएँगे futures).
Never तू/तुम. Inanimate gender follows common Hindi usage
(सर्वर/टाइटल/कलेक्शन masculine; लाइब्रेरी/प्लेलिस्ट/सेटिंग्स feminine).

## Address & voice

- Second person: always आप. Imperatives in -ें (करें, चुनें, देखें, जाएँ).
- Short, plain, friendly streaming-app Hindi. Common English loanwords stay in
  Devanagari where Indian apps use them (सेटिंग्स, सर्च, प्लेलिस्ट) rather than
  Sanskritised coinages.

## Punctuation & typography

- Full stop: Devanagari danda । (not .). Never the CJK 。.
- Quotes: “ ” kept as in English.
- Ellipsis: … (U+2026) kept.
- Apostrophe: ’ (U+2019) only; ASCII ' never appears. Most Hindi phrasing
  avoids it entirely (e.g. album’s page → एल्बम के पेज पर).
- Arrow → and en dash – kept (ranges, {from} → {to}, lifespans).
- ★ kept. % and units (Mbps, GB, p in 1080p, h/m/s short forms localised as
  घं/मि/से) kept adjacent as in English.
- ICU: every {argument} kept verbatim; plural/select keys and =0 branches
  kept; select keys never reordered. Hindi adds one wherever English has only
  other (one/other required). Durations: short {hours}घं {minutes}मि,
  {seconds}से; long घंटा/घंटे, मिनट, सेकंड.
- Leading/trailing spaces match English exactly.

## Judgement calls a reviewer should check

- Search → सर्च (noun/tab) follows the loanword convention; verb forms use
  खोजें. If reviewers prefer खोजें everywhere, it is a mechanical swap.
- Play → चलाएँ (चलाना, “to run/play media”) rather than transliterated प्ले;
  प्लेबैक kept for the noun “playback”, प्लेयर for “player”. Queue → कतार.
- Title → टाइटल everywhere (media item), never शीर्षक; consistent with
  streaming-app usage.
- Watched → देखा हुआ; unwatched → अनदेखा; played/unplayed → चलाया हुआ /
  न चलाया हुआ; finished → पूरा/समाप्त by context.
- Mark as watched/unwatched → देखा हुआ/अनदेखा चिह्नित करें.
- “Up next” → आगे देखें (both home row and player queue) for consistency.
- Count nouns kept invariable where Hindi does (आइटम, एपिसोड, टाइटल,
  डाउनलोड, सेकंड, मिनट); घंटे/फ़िल्में/किताबें/गाने inflect in other branches.
- Relative time: मिनट/घंटा/दिन पहले; Just now → अभी; Yesterday → कल.
- Gendered futures use the respectful plural (कर सकेंगे, जाएँगे) for {name}
  subjects to stay gender-neutral.
- Management verbs: Manage → प्रबंधित करें; the “owner” is मालिक (not स्वामी).
- kid-oriented “Unrated titles” → बिना रेटिंग वाले टाइटल; “Allow unrated
  titles” likewise.
- web.player.channelUp/Down are swapped vs player.channelUp/Down in English
  (“Previous/Next channel” vs “Next/Previous channel”); translated each as
  written (पिछला/अगला चैनल).
- activation.termsNote and rcloneConfigExample keep real newlines from source.
- quality.height skeleton {height, number, ::group-off}p and tuner/code
  examples (ABCD EFGH, 192.168.1.20:32500, America/New_York, [drive]) kept
  byte-identical apart from surrounding words.
