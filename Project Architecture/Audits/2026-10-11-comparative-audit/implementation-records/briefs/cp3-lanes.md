- **Apple:** plain HTTP is allowed to any address **on the local network only** (App Store rules forbid remote insecure connections). Not app-wide arbitrary loads.
- **Any browser that can reach the local web UI must be fully functional with no special setup.**
- **Building a library from scratch must be quick.** If it isn't, fix it now.

- **Secure connection:** explained simply in Server Settings, and the default for most users: with a Portico Account, a new server is claimed/registered and gets its certificate as soon as it is created and named by a signed-in user.
- **Dropped from the feature lists:** spoiler controls, writing NFO/artwork beside media, country rating tables, per-library unrated/kids allow-list, unifying profile and account label rules.
