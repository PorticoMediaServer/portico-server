# Getting help

Portico is prerelease software and currently provides community-style support only.

For installation questions, bug reports, and feature requests, use the issue tracker for the affected repository. Search existing issues first and provide your Portico version, platform, installation method, and sanitized logs.

For private contact that is not suitable for an issue, email [admin@getportico.tv](mailto:admin@getportico.tv).

The project does not provide emergency, paid, or guaranteed-response support. Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
